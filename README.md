# iCore Store

Інтернет-магазин техніки Apple з вітриною, кошиком і адмін-панеллю.

Стек: **HTML / CSS / JavaScript**, **Node.js (Express)**, **PostgreSQL**.

## Запуск

Потрібен лише **Node.js 18+**. База піднімається сама.

У терміналі з папки проєкту:

```bash
chmod +x start.sh
./start.sh
```

Або:

```bash
npm install
npm start
```

Браузер відкриється автоматично. Якщо порт 3000 зайнятий, сервер візьме наступний вільний.

### Адмін-панель

- Адреса: `/admin/login.html`
- Email: `admin@icore.store`
- Пароль: `Admin123!`

Облікові дані змінюються в `.env`.

### PostgreSQL (Neon)

У `.env` вкажіть рядок підключення:

```
USE_POSTGRES=1
DATABASE_URL=postgresql://USER:PASSWORD@HOST/neondb?sslmode=require
```

При старті сервер сам створює таблиці та адміна.

## Можливості

- Каталог iPhone, AirPods і Mac з актуальним імпортом Ябко; інші категорії можна наповнювати з адмінки
- Пошук, фільтри, сортування
- Кошик і оформлення замовлення
- Адмінка: статистика, товари, статуси замовлень

### Імпорт товарів з Ябко

У розділі **Адмінка → Товари** доступні тестовий запуск, імпорт і повторне оновлення. Імпортер обходить усі сторінки категорій iPhone, AirPods і Mac, відкриває кожну сторінку товару й оновлює позиції за ID Ябко.

З командного рядка:

```bash
npm run import:jabko -- --dry-run --limit=3  # перевірити по одному товару з кожної категорії, без запису
npm run import:jabko -- --scan-only          # пройти всю пагінацію й порахувати каталог
npm run import:jabko                         # імпортувати або оновити весь каталог
```

Перший повний імпорт один раз очищає старі товари, залишаючи замовлення, акаунти й налаштування. Для повторних запусків товари зіставляються за стабільним ID джерела; зниклі з каталогу Ябко позиції приховуються.

Націнка задається у `.env`:

```dotenv
JABKO_IPHONE_MARKUP_PERCENT=15
JABKO_OTHER_MARKUP_PERCENT=0
```

Націнка iPhone за замовчуванням — 15%. Для AirPods і Mac — 0%; ці значення можна змінити без редагування імпортера. Щоб оновлювати товари за розкладом, додайте `npm run import:jabko` у cron або планувальник системи (наприклад, кожні дві години). Автоматичний запуск не вмикається самостійно.
